### 요약 내용

**군중 AI 이동 시스템 구현 완료 (StateTree 기반)**

오늘은 StateTree를 활용한 군중 NPC의 기본 이동 시스템을 구현했습니다.

#### 1. StateTree 학습 및 아키텍처 설계
- **StateTree 구조 이해**
  - State는 에디터에서 비주얼 작성
  - Task는 C++ (`FStateTreeTaskBase` 상속)로 구현
  - Condition은 C++ (`FStateTreeConditionBase` 상속)로 구현
- **Task 라이프사이클**
  - `EnterState()`: State 진입 시 1번 호출 (초기화)
  - `Tick()`: 매 프레임 호출 (Running 상태일 때)
  - `ExitState()`: State 종료 시 1번 호출 (정리)
- **설계 방침 결정**
  - StateTree 1개 + DataAsset으로 타입별 차별화 (Data-Driven)
  - 3가지 직업군(시장 아지매/군인/애기)을 하나의 StateTree로 통합
