## 대화 시스템 구조 설명

### 1. 전체 개요

**목표:** 4명의 NPC (0번 상인 + 1,2,3번 손님)가 특정 위치에 모이면 자동으로 대화를 시작하고, 집 가기 전까지 무한 반복

**대화 순서:**
```
0번 상인 질문 → 1번 손님 → 2번 손님 → 3번 손님 → 0번 상인 답변
→ 3초 대기 → 다시 처음부터 반복
```

**사운드 규칙:**
- 0번 상인: 항상 사운드 배열의 `[0]` 재생
- 1,2,3번 손님: 사운드 배열의 `[1] ~ [끝]` 중 랜덤 재생

### 8. 요약

**핵심 개념 3가지:**

1. **자리 예약 vs 도착 확인 분리**
   - 예약 (EnterState): `inCrowd = true` → 동시 접근 방지
   - 도착 (Tick): `isArrived = true` → 대화 시작 조건

2. **델리게이트 순환 바인딩**
   - 말 끝나면 → 다음 화자에게 델리게이트 바인딩
   - 이전 화자 언바인딩 → 메모리 누수 방지

3. **StateTree Self-Transition**
   - `TalkState → TalkState` 트랜지션
   - Wait 거치지 않고 바로 다음 대화로 전환
   - 빠르고 안정적

**성공 조건:**
- 4명 모두 `isArrived == true`
- `DialogueRound == 0`일 때 StartDialogue() 호출
- 0번 NPC에 사운드[0] 설정
- 1,2,3번 NPC에 사운드[1~끝] 설정
- StateTree에 TalkState → TalkState 트랜지션 추가
