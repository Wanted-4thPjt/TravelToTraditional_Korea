### 추천 아키텍처
Layered Responsibility Pattern
```
  ┌─────────────────────────────────────────┐
  │ MainPlayer (PlayerController)           │ ← 입력 받기
  │  - Input Binding (E키, 점프 등)          │
  │  - Server RPC 호출                      |
  └────────────┬────────────────────────────┘
               │ Server_PerformAction(ActionType)
               ▼
  ┌─────────────────────────────────────────┐
  │ BaseContentManager (Server Authority)   │  ← 게임 로직 처리
  │  - ValidateAction()                     │
  │  - ProcessAction()                      │
  │  - UpdateScore/State                    │
  └────────────┬────────────────────────────┘
               │ Multicast_BroadcastResult()
               ▼
  ┌─────────────────────────────────────────┐
  │ All Clients                             │  ← UI 업데이트, VFX
  │  - RepNotify → UI 갱신                  │
  │  - OnRep_Score() → 스코어보드 업데이트     │
  └─────────────────────────────────────────┘
```

### ENetRole

열거형 값:               DisplayName<br>

1. ROLE_None:               None
   - 네트워크 역할을 가지지 않은 액터입니다. 일반적으로 복제가 비활성화된 액터(예: 로컬 전용 UI 액터, 일부 편집기 전용 액터)가 이 값을 가집니다.
2. ROLE_SimulatedProxy:	   Simulated Proxy
   - 다른 플레이어의 클라이언트 머신에 존재하는 액터의 복사본(Proxy)입니다. 이 액터는 네트워크를 통해 **서버로부터 데이터를 수신(복제)**받아 시뮬레이션합니다. (예: 멀리 있는 다른 플레이어 캐릭터)
3. ROLE_AutonomousProxy:	 Autonomous Proxy	
   - 현재 이 컴퓨터를 사용하는 플레이어가 조작하는 액터의 복사본입니다. 이 액터는 로컬 입력 권한을 가지며, **입력 및 액션을 서버에 전송(RPC)**할 수 있습니다. (예: 내가 조작하는 캐릭터)
4. ROLE_Authority:          Authority
   - 액터의 진정한 마스터 인스턴스입니다. 이 액터는 서버에서 실행되며, 게임 플레이 로직을 실행하고, 모든 변수와 이벤트를 다른 모든 클라이언트로 복제할 권한을 가집니다. (예: 서버에 존재하는 모든 액터, 특히 Dedicated Server에서)
5. ROLE_MAX:	               Hidden
   - 	열거형의 최대값을 나타내는 내부용 값입니다.
