### 2. Lazy Initialization Pattern (MainPlayer)

**문제**: 모든 Content Component를 미리 생성하면 메모리 낭비

**해결**: 처음 사용 시 생성 → 캐싱 → 재사용

#### MainPlayer.h 수정
```cpp

    UPROPERTY()
```

#### MainPlayer.cpp 구현
```cpp
// UE_TTTK/Source/UE_TTTK/Private/MainPlayer.cpp
void AMainPlayer::ActivateContentInput(UBaseContentManager* manager)
{
    if (!manager) return;

    // 1. 기존 Component 비활성화
    DeactivateContentInput();

    // 2. Lazy Initialization
    TSubclassOf<UBaseContentComponent> componentClass = manager->GetContentInputComponentClass();
    UBaseContentComponent* contentComp = GetOrCreateContentInput(componentClass);

    if (!contentComp) return;

    // 3. 활성화
    activeContentInput = contentComp;
    contentComp->ActivateContentInput(manager);

    // 4. Input Bindings 설정
    if (APlayerController* PC = Cast<APlayerController>(GetController()))
    {
        if (UEnhancedInputComponent* EIC = Cast<UEnhancedInputComponent>(PC->InputComponent))
        {
            contentComp->SetupInputBindings(EIC);
        }
    }
}

UBaseContentComponent* AMainPlayer::GetOrCreateContentInput(TSubclassOf<UBaseContentComponent> componentClass)
{
    if (!componentClass) return nullptr;

    // 1. 캐시 확인
    if (UBaseContentComponent** CachedComponent = cachedContentInputs.Find(componentClass))
    {
        if (IsValid(*CachedComponent))
        {
            return *CachedComponent;  // 재사용!
        }
    }

    // 2. 새로 생성
    UBaseContentComponent* NewComponent = NewObject<UBaseContentComponent>(
        this, componentClass, NAME_None, RF_Transient);

    if (!NewComponent) return nullptr;

    // 3. 초기화 및 캐싱
    NewComponent->RegisterComponent();
    cachedContentInputs.Add(componentClass, NewComponent);

    return NewComponent;
}

void AMainPlayer::DeactivateContentInput()
{
    if (activeContentInput && activeContentInput->IsContentActive())
    {
        activeContentInput->DeactivateContentInput();
        activeContentInput = nullptr;
    }
}
```

**성능 이점**:
- 첫 생성: ~0.1ms
- 재사용: ~0.001ms (100배 빠름)
- 메모리: 사용하는 Component만 생성

### 3. Client Authority Pattern 구현

**문제**: 타이밍 게임에서 네트워크 지연(RTT 100ms) → 사용자 경험 저하

**해결**: Client에서 모든 게임 로직 실행 → Server는 결과만 검증

#### 아키텍처
```
Client                              Server
------                              ------
1. 버튼 입력
2. AnimMontage 재생
3. AnimNotify → 타이밍 판정
4. 콤보 업데이트 (로컬)
5. UI/이펙트 재생 (즉시)
6. 제기 물리 업데이트 (로컬)
   ↓
7. Server_ReportKick(timing) ----→ 8. 타이밍 검증
                                   9. 치팅 방지 체크
                                   10. Score 저장
                                   11. (필요시) Client_OnValidationFailed
```

#### JegiChagiContentComponent.cpp 구현
```cpp
// Input 처리 - AnimMontage만 재생
void UJegiChagiContentComponent::OnKickRightInput()
{
    if (!bContentActive || !myJegi) return;

    if (AMainPlayer* player = Cast<AMainPlayer>(GetOwner()))
    {
        if (kickRightMontage)
        {
            player->PlayAnimMontage(kickRightMontage);
        }
        else
        {
            // Fallback
            OnAnimNotify_KickContact();
        }
    }
}

// AnimNotify Callback - 타이밍 판정 실행
void UJegiChagiContentComponent::OnAnimNotify_KickContact()
{
    if (!bContentActive || !myJegi) return;

    // 1. 타이밍 판정 (로컬)
    EKickTiming timing = CalculateLocalTiming();

    // 2. 콤보 업데이트 (로컬)
    UpdateLocalCombo(timing);

    // 3. 피드백 재생 (즉시)
    PlayLocalFeedback(timing);

    // 4. 물리 적용 (로컬)
    if (timing != EKickTiming::Missed)
    {
        jegiVelocity.Z = kickForce;
        FVector newLocation = myJegi->GetActorLocation();
        newLocation.Z += 10.f;
        myJegi->SetActorLocation(newLocation);
        lastJegiPosition = newLocation;
    }

    // 5. Server에 결과 전송
    float timestamp = GetWorld()->GetTimeSeconds();
    Server_ReportKick(timing, timestamp);
    lastKickTime = timestamp;
}

// Client-Side 타이밍 판정
EKickTiming UJegiChagiContentComponent::CalculateLocalTiming()
{
    float jegiHeight = myJegi->GetActorLocation().Z;
    float playerHeight = GetOwner()->GetActorLocation().Z;
    float relativeHeight = jegiHeight - playerHeight;

    float diff = FMath::Abs(relativeHeight - optimalKickHeight);

    if (diff <= perfectWindow * optimalKickHeight)
        return EKickTiming::Perfect;
    else if (diff <= greatWindow * optimalKickHeight)
        return EKickTiming::Great;
    else if (diff <= goodWindow * optimalKickHeight)
        return EKickTiming::Good;
    else
        return EKickTiming::Missed;
}

// Client-Side 콤보 업데이트
void UJegiChagiContentComponent::UpdateLocalCombo(EKickTiming timing)
{
    if (timing == EKickTiming::Missed)
    {
        localCombo = 0;
        localMissedCount++;
    }
    else
    {
        localCombo++;
        if (localCombo > localMaxCombo)
            localMaxCombo = localCombo;

        switch (timing)
        {
            case EKickTiming::Perfect: localPerfectCount++; break;
            case EKickTiming::Great: localGreatCount++; break;
            case EKickTiming::Good: localGoodCount++; break;
        }
    }
}

// Server RPC - 결과 검증
void UJegiChagiContentComponent::Server_ReportKick_Implementation(EKickTiming timing, float timestamp)
{
    if (!jegiManager) return;

    // 1. 타이밍 검증 (치팅 방지)
    float currentTime = GetWorld()->GetTimeSeconds();
    float timeDiff = currentTime - timestamp;

    if (timeDiff > 0.5f)  // 500ms 이상 차이 = 의심
    {
        Client_OnValidationFailed(TEXT("Timestamp mismatch"));
        return;
    }

    // 2. 연속 킥 검증
    if (lastKickTime > 0.f && (timestamp - lastKickTime) < 0.1f)  // 100ms 미만 = 의심
    {
        Client_OnValidationFailed(TEXT("Kick too fast"));
        return;
    }

    // 3. 검증 통과 → 저장은 라운드 종료 시
    lastKickTime = timestamp;
}

// Client RPC - 검증 실패
void UJegiChagiContentComponent::Client_OnValidationFailed_Implementation(const FString& reason)
{
    UE_LOG(LogTemp, Warning, TEXT("Server rejected kick: %s"), *reason);
    // UI에 경고 표시
}
```

**장점**:
- **즉각적 피드백**: 0ms 지연
- **Server 부하 감소**: 결과만 검증
- **치팅 방지**: 타이밍, 물리 검증

**단점**:
- Client 신뢰 필요 → Server 검증으로 보완
- 약간의 불일치 가능 → 정정 RPC로 해결

```cpp
// 효율적 방식
void UJegiChagiContentManager::SaveRoundResult(APlayerController* player, const FJegiRoundRecord& result, bool bSuccess)
{
    FContentParticipatingPlayerData* data = contentPlayersData.FindByPredicate(
        [player](const FContentParticipatingPlayerData& d) { return d.controller == player; });

    if (!data) return;

    // 즉시 축적!
    // 0: MaxCombo - 최댓값 갱신
    int32 currentMaxCombo = FCString::Atoi(*data->recordedCustomValues[0]);
    if (result.maxCombo > currentMaxCombo)
    {
        data->recordedCustomValues[0] = FString::FromInt(result.maxCombo);
        data->recordedScore = result.maxCombo;  // Score도 동기화
    }

    // 1: Perfect Count - 누적
    int32 currentPerfect = FCString::Atoi(*data->recordedCustomValues[1]);
    data->recordedCustomValues[1] = FString::FromInt(currentPerfect + result.perfectCount);

    // 2: Great Count - 누적
    int32 currentGreat = FCString::Atoi(*data->recordedCustomValues[2]);
    data->recordedCustomValues[2] = FString::FromInt(currentGreat + result.greatCount);

    // 3: Good Count - 누적
    int32 currentGood = FCString::Atoi(*data->recordedCustomValues[3]);
    data->recordedCustomValues[3] = FString::FromInt(currentGood + result.goodCount);

    // 4: Missed Count - 누적
    int32 currentMissed = FCString::Atoi(*data->recordedCustomValues[4]);
    data->recordedCustomValues[4] = FString::FromInt(currentMissed + result.missedCount);

    // 5: Total Kicks - 누적
    int32 currentTotalKicks = FCString::Atoi(*data->recordedCustomValues[5]);
    data->recordedCustomValues[5] = FString::FromInt(currentTotalKicks + result.totalKicks);
}

void UJegiChagiContentManager::CalculateFinalRankings()
{
    // 데이터 이미 축적 완료! 순위만 계산
    contentPlayersData.Sort([](const FContentParticipatingPlayerData& a, const FContentParticipatingPlayerData& b)
    {
        return a.recordedScore > b.recordedScore;
    });

    for (int32 i = 0; i < contentPlayersData.Num(); ++i)
    {
        contentPlayersData[i].rank = i + 1;
    }
}
```

```cpp
AJegi::AJegi()

    // 충돌 설정

    }
    SetRootComponent(sphereCollider);

    meshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
    meshComponent->SetupAttachment(sphereCollider);
    meshComponent->SetCollisionObjectType(ECC_WorldDynamic);
    meshComponent->SetCollisionResponseToAllChannels(ECR_Ignore);
    meshComponent->SetCollisionResponseToChannel(ECC_WorldStatic, ECR_Block);
    meshComponent->SetCollisionEnabled(ECollisionEnabled::QueryAndPhysics);

    sphereCollider->SetSphereRadius(10.f);
    meshComponent->SetRelativeLocation(FVector(0.f, 0.f, 32.f));
    SetActorRelativeScale3D(FVector(1.f));

    // 물리 Movement
    movementComponent = CreateDefaultSubobject<UProjectileMovementComponent>(TEXT("Movement"));

        movementComponent->SetIsReplicated(true);
        movementComponent->bShouldBounce = false;
        movementComponent->bSimulationEnabled = true;
        movementComponent->ProjectileGravityScale = 1.f;
        movementComponent->MaxSpeed = 600.f;
        movementComponent->Bounciness = 0.f;
        movementComponent->bSweepCollision = true;
    }
```

## 발생한 문제 및 해결

### 문제 1: TSubclassOf 모호성 오류
```
Error C2445: 조건식의 결과 형식이 모호합니다.
'TSubclassOf<AJegi>' 및 'UClass *' 형식이 여러 공용 형식으로 변환될 수 있습니다.
```

**원인**:
```cpp
// WRONG
AJegi* jegi = GetWorld()->SpawnActor<AJegi>(
    IsValid(jegiClass) ? jegiClass : AJegi::StaticClass(),  // 모호함!
    ...
);
```

**해결**:
```cpp
// CORRECT
UClass* SpawnClass = jegiClass ? jegiClass.Get() : AJegi::StaticClass();
AJegi* jegi = GetWorld()->SpawnActor<AJegi>(SpawnClass, ...);
```
