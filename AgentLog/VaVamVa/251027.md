### 3. Delegate 구조 개선
- **FOnClientFinished → FOnStateChanged 전환**:
  - `DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnStateChanged, APlayerController*, playerController, EInteractableState, newState)`
  - 단일 return 값 델리게이트 → 멀티캐스트 상태 변경 이벤트
- **TryFinish() 함수 제거**:
  - 중복된 종료 로직 제거
  - 상태 전환으로 통일 (`TryChangeState(OutOfBound)`)
- **TryChangeState()에 OnStateChanged 브로드캐스트 추가**:
  - 모든 상태 변경 시 자동으로 이벤트 발생
  - 컴포넌트가 상태 변경을 감지하여 반응

### 4. 이벤트 기반 OutOfBound 감지 구현
- **OnInteractableStateChanged() 콜백 추가**:
  - InteractableComponent의 OnStateChanged에 바인딩

  - Timer 없이 즉각적인 반응
- **OnUICloseRequested() 개선**:
  - `TryFinish()` 호출 → `TryChangeState(OutOfBound)` 호출
  - 일관된 상태 전환 패턴 유지

- **TryInteract() 단순화**:
  - OnClientFinished 체크 로직 제거
  - OnClientInteraction 브로드캐스트만 수행
