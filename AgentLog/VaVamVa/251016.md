### 해결된 이슈

1. ✅ **멀티플레이 복제 초기화 순서 문제**
   - 컴포넌트 생성자에서 SetIsReplicated → SetIsReplicatedByDefault 사용

2. ✅ **Server RPC "No owning connection" 오류**
   - 서버에서 복제된 캐릭터가 LineTrace를 실행하여 Server RPC를 호출하려고 시도
   - IsLocallyControlled() 체크로 자신의 캐릭터에서만 LineTrace 실행하도록 수정

3. ✅ **ActorComponent에서 하위 컴포넌트 생성 문제**
   - CreateDefaultSubobject는 Actor/SceneComponent에서만 사용
   - ActorComponent는 NewObject + AddInstanceComponent 방식 사용

### 학습 내용

1. **컴포넌트 복제 설정 타이밍**
   - 생성자: `SetIsReplicatedByDefault(true)` 또는 `bReplicates = true`
   - 런타임: `SetIsReplicated(true)` (초기화 완료 후)
   - 복제는 컴포넌트의 "정체성"으로, 생성 시 결정되어야 함

2. **Server RPC 실행 조건**
   - 클라이언트에서 호출 시: Owner Connection을 통해 서버로 전달
   - 서버에서 호출 시: "No owning connection" 오류 발생
   - 복제된 Actor(다른 플레이어의 캐릭터)에서 호출 시: 소유권이 없어 오류 발생

3. **ActorComponent vs SceneComponent**
   - ActorComponent: 로직만 담당, Transform 없음, 하위 컴포넌트 불가
   - SceneComponent: Transform 보유, 계층 구조 형성 가능
   - CreateDefaultSubobject는 Owner의 컨텍스트에서 동작, ActorComponent는 Owner가 될 수 없음

{
    PrimaryComponentTick.bCanEverTick = false;
    SetIsReplicatedByDefault(true);  // ✅ 생성자에서 올바른 함수 사용
}

// ViewComponent.h
UFUNCTION(BlueprintCallable)  // ✅ 일반 함수로 변경
void EnableTrace(bool bEnable);

// MainPlayer.cpp - BeginPlay
void AMainPlayer::BeginPlay()
{
    Super::BeginPlay();

    if (IsLocallyControlled())  // ✅ 자신의 캐릭터에서만 실행
    {
        viewComponent->OnViewSthByLineTrace.AddDynamic(this, &AMainPlayer::OnViewInteractableActor);
        viewComponent->EnableTrace(true);
    }
}

// InteractableComponent.cpp - BeginPlay
void UInteractableComponent::BeginPlay()
{
    Super::BeginPlay();

    // ✅ 런타임에 동적 생성
    interactionSphere = NewObject<USphereComponent>();
    GetOwner()->AddInstanceComponent(interactionSphere);
    interactionSphere->AttachToComponent(GetOwner()->GetRootComponent(), ...);
    interactionSphere->RegisterComponent();

    interactionGuideComponent = NewObject<UWidgetComponent>();
    GetOwner()->AddInstanceComponent(interactionGuideComponent);
    interactionGuideComponent->AttachToComponent(GetOwner()->GetRootComponent(), ...);
    interactionGuideComponent->RegisterComponent();
}
